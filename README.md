## 🧪 Module Deep Dive — Under the Hood

### The Loader
On execution, Sentinel-Hub runs a **preflight sequence**: it fingerprints the executor environment, verifies the Lua version, and checks for known incompatibilities. If the ground is solid, it proceeds to the module registry.

### The Registry
Modules self-register by declaring a manifest table with `name`, `version`, `entry`, and `dependencies`. The registry resolves load order via topological sort — a fancy way of saying "do the prerequisites first."

### The Renderer
The UI is drawn with a custom lightweight renderer built atop Roblox's native `Instance` API. It's not a third-party UI library. It's ours, and it's small enough to read in one sitting.

### The Translator
Localization uses a **flat key-value store** with fallback chaining. If a key is missing in Japanese, it falls back to English — never to a blank string, never to a raw key ID.

### The Event Bus
Modules communicate through an internal pub/sub bus. This decouples features from each other, so removing one module never breaks another.
